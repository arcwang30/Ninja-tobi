# NINJA 鳶 TOBI

依據《NINJA TOBIKUN 提案簡報》製作的忍者跳躍遊戲。HTML5 Canvas + 原生 JavaScript，免建置，手機／平板／電腦瀏覽器皆可玩，並支援 PWA（加到主畫面、離線遊玩）。

## 執行

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

開啟 http://localhost:8080 。要用手機／平板測試：以系統管理員執行 `serve.ps1 -Lan`，再用同網路裝置連 `http://<電腦IP>:8080`（搖晃偵測與 PWA 安裝在 iOS 需 HTTPS，正式上線請放到 HTTPS 主機，例如 GitHub Pages）。

Artifact 環境的限制：不能偵測搖晃手機（改點左上卷軸圖示發動忍法；QTE「晃動」可用左右快速來回滑動）、不能加到主畫面、沒有離線快取。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` / `style.css` | 選單、商店、排行、結算等 UI |
| `lang.js` | 多語系文字（繁中／日文／英文），每個字串是 `[繁中, 日文, 英文]` |

| `serve.ps1` / `build-artifact.ps1` | 本機伺服器／產生 Artifact 版頁面 |

## 玩法

- **模式**：只有 Roguelike「忍者修行」。主線 風・林・火・山 四幕，通關後可選擇繼續挑戰「無盡之塔」（每一輪死亡區域 +15% 速度、敵人 +30%），或直接結算。
- **移動**：自動彈跳，按住左右滑動移動。左右兩側是牆壁（不能穿屏），空中往牆推會蹬牆跳，每次落地或斬殺前限一次。
- **彈射斬**：手指按住不動 0.15 秒進入瞄準，時間變 0.3 倍（最多 2.5 秒）。往反方向拉，顯示含牆壁反射的軌跡、路線上會斬到的敵人（紅圈），方向接近敵人約 11° 內會自動吸附（金色準星）。放開發射；拉不到 22px 就是取消。往上拉（瞄準下方）是急降斬。快速上滑／下滑仍可直接出招。
- **氣**：衝刺斬／急降斬各消耗 1 格，斬殺回 0.5 格，平時緩慢回復。
- **魂與升級**：斬殺敵人掉落魂（經驗）與小判，先往上噴再慢慢落下，靠近吸收、掉出畫面就消失。經驗條滿就升級三選一：自動技能（最多同時 4 種、各 Lv5）或被動強化。擊破魔王或大天狗開寶箱再選一次。只有自己斬殺的敵人會回「氣」，技能擊殺只給魂。
- **自動技能**：攻擊（手裡劍、苦無環、雷遁、風刃）、防禦（結界、金剛氣）、輔助（式神鳥、疾風），數值在 `game.js` 的 `SKV` 表。
- **空中連斬**：不落地連續斬殺累積連斬，落地結算；10 連斬進入狂熱（得分 ×2）。
- **敵人**：雜兵（瘦／中／胖、烏鴉群、小天狗）碰到就斬；攻擊型敵人的攻擊才會傷人：手裡劍忍者（直線飛鏢）、弓忍（拋物線箭）、土遁忍者（藏在地板，靠近時冒出往上射苦無）、蜘蛛（吐絲減速）、鬼火（飄向玩家，直接碰到會受傷）。盾忍者從下方撞會被打落、爆彈忍者連鎖爆炸、菁英帶「迅捷／分裂／鐵壁」詞綴並掉寶箱。每 11～16 秒一次波次（越後面越頻繁），可一路連斬上去的「敵人階梯」也會出現。
- **中 BOSS 與進化**：每一幕中段出現大天狗（扇形射擊、限時 25 秒），擊倒開寶箱。技能 Lv5 ＋ 對應被動，打開魔王或大天狗的寶箱時會出現進化（8 種，見 `game.js` 的 `EVO` 表）。
- **角色**：起始技能不同（鳶＝手裡劍、蒼＝苦無環、桜＝風刃、影＝雷遁），開局不再三選一。
- **節奏**：每一幕 1200m（約 1～2.5 分鐘），主線約 7～10 分鐘；地形難度在 1600m 達到最高，之後每一幕敵人密度 +12%。
- **地板機關**：一般／跳台（2 倍）／半毀地板／移動地板／釘刺。
- **忍法卷軸**：點卷軸圖示／空白鍵／搖晃手機，發動「豪天翔」。
- **死亡區域**：火海／海嘯／怪獸，隨時間上升，掉入扣 HP 並被救回。
- **BOSS**：四種技能（踩破站台／降速／冰凍／反彈）+ QTE（連打／劃擊／晃動）+「一擊必殺」，擊破後三選一「秘傳」。
- **局外成長**：整備商店（角色、修行：起始 HP、起始卷軸、小判加成、重抽次數）、本機排行榜、成就。
- **語言**：第一次開啟依系統語言自動選擇，設定裡可切換 中文／日本語／English。

調參集中在 `game.js` 開頭的常數與表格（`ENEMY`、`PERKS`、`MODS`、`META`、`STAGE_PX`、`AIM_*`、`WALL` 等）。
